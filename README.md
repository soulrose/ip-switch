# IP Switch รพ.

ย้าย IP static ของ รพ. ไปมาระหว่างสาย LAN กับ Wi-Fi หรือกลับเป็น DHCP ด้วยการกดปุ่มเดียว

## ใช้งาน

1. เปิดจาก OffLab, ดับเบิลคลิก `start.bat` หรือตัว portable `IpSwitch.exe` แล้วกด Yes ที่ Windows ถามสิทธิ์ admin
2. ใช้ครั้งแรก: โปรแกรมอ่าน IP ที่เครื่องใช้อยู่และบันทึกให้เอง ตรวจใน "ตั้งค่า IP ของเครื่องนี้" ได้
3. กดปุ่มที่ต้องการ
   - **สาย LAN** ใส่ IP ที่การ์ด LAN ส่วน Wi-Fi กลับเป็น DHCP
   - **Wi-Fi** ใส่ IP ที่การ์ด Wi-Fi ส่วน LAN กลับเป็น DHCP
   - **อัตโนมัติ** ทั้งสองการ์ดเป็น DHCP ใช้ตอนอยู่นอก รพ.

**ปุ่ม Wi-Fi ต้องให้ Wi-Fi ของ รพ. เชื่อมต่อได้** กดแล้วโปรแกรมต่อ Wi-Fi ที่เคยใช้ได้ให้เอง ถ้าไม่ติดใน 25 วินาทีจะเปิดรายการ Wi-Fi ให้เลือก และรอได้ 3 นาที Windows ไม่ยอมปิด DHCP ของการ์ด Wi-Fi ที่ยังไม่ได้เชื่อมต่อ (ทุกคำสั่งบอกว่าสำเร็จแต่ไม่เปลี่ยนอะไร) จึงต้องรอให้ต่อติดก่อน ถ้าไม่ติดจะไม่เปลี่ยนอะไรเลย LAN ยังเหมือนเดิม

ปุ่มของโหมดที่ใช้อยู่จะมีกรอบสีฟ้าและป้าย "ใช้อยู่" ถ้าการ์ดอีกตัวยังมีค่าเก่าค้างอยู่ จะขึ้นเป็นตัวหนังสือสีส้ม ให้กดปุ่มเดิมอีกครั้งเพื่อล้าง

ค่าที่ตั้งเก็บไว้ใน `config.json` ในโฟลเดอร์นี้ ถ้าเครื่องมีการ์ด LAN หลายตัว (เช่น dock USB) เลือกการ์ดเองได้ในหน้าตั้งค่า

## ตัว portable ให้เครื่องอื่น

ส่งไฟล์เดียว `dist\IpSwitch.exe` ให้เพื่อน หรือโหลดจาก <https://github.com/soulrose/ip-switch/raw/main/dist/IpSwitch.exe> ไม่ต้องติดตั้ง ดับเบิลคลิกเปิดได้เลย (วางไว้ใน USB หรือโฟลเดอร์ไหนก็ได้)

- เปิดครั้งแรกจะอ่าน IP ที่เครื่องใช้อยู่และบันทึกให้ทันที ถ้าไม่ใช่ IP ของ รพ. แก้ได้ใน "ตั้งค่า IP ของเครื่องนี้"
- ค่าของเครื่อง (`config.json`, `last-run.log`) เก็บไว้ข้างไฟล์ exe ถ้าโฟลเดอร์นั้นเขียนได้ ไม่งั้นเก็บใน `%LOCALAPPDATA%\IpSwitch`
- ตัวโปรแกรมแตกไว้ที่ `%LOCALAPPDATA%\IpSwitch\app-<version>` ทำครั้งเดียวต่อเวอร์ชัน

## อัปเดต

เปิดโปรแกรมแล้วจะตรวจเวอร์ชันใหม่จาก GitHub ให้เอง ถ้ามีจะขึ้นแถบ "มีเวอร์ชันใหม่" ด้านบน หรือกดปุ่ม "ตรวจอัปเดต" ด้านล่างเมื่อไรก็ได้

- ตัว portable: กด **อัปเดตเลย** โปรแกรมโหลด `IpSwitch.exe` ตัวใหม่มาแทนไฟล์เดิม แล้วเปิดใหม่ให้ ค่า IP ของเครื่องยังอยู่
- เปิดจาก OffLab หรือ `start.bat`: ปุ่มเป็น **ดาวน์โหลด** ให้โหลดตัว portable ไปใช้ หรือ `git pull` ในโฟลเดอร์นี้
- จาก command line: `IpSwitch.ps1 -CheckUpdate` บอกเวอร์ชันล่าสุด และ `IpSwitch.ps1 -Update -ExePath <ไฟล์ IpSwitch.exe>` อัปเดตตัว portable

### ออกเวอร์ชันใหม่

ต้องเพิ่มเลขเวอร์ชันทุกครั้งที่แก้โค้ด เพราะเครื่องที่เคยเปิดจะแตกไฟล์ใหม่เฉพาะเมื่อเลขเวอร์ชันเปลี่ยน

1. แก้เลขใน `VERSION` และเขียนสิ่งที่เปลี่ยนใน `CHANGELOG.md` หัวข้อ `## <เลขเวอร์ชัน>` (ข้อความนี้ขึ้นในแถบอัปเดต)
2. สร้าง exe:
   ```bat
   powershell -ExecutionPolicy Bypass -File portable\build-portable.ps1
   ```
3. commit แล้ว push พร้อม tag `v<เลขเวอร์ชัน>` ทุกเครื่องจะเห็นเวอร์ชันใหม่จาก tag นี้
   ```bat
   git tag v1.3.0
   git push origin main --tags
   ```

## ใช้จาก command line หรือ shortcut

```bat
powershell -ExecutionPolicy Bypass -File IpSwitch.ps1 -Apply Lan
powershell -ExecutionPolicy Bypass -File IpSwitch.ps1 -Apply Wifi
powershell -ExecutionPolicy Bypass -File IpSwitch.ps1 -Apply Dhcp
powershell -ExecutionPolicy Bypass -File IpSwitch.ps1 -Apply Wifi -DryRun
```

`-Apply` ต้องรันแบบ admin ส่วน `-DryRun` บอกว่าจะเปลี่ยนอะไรบ้างโดยไม่แตะเครื่องและไม่ต้องใช้ admin

## สิ่งที่แก้จากชุด .bat เดิม (setupIpV4)

| ปัญหาในของเดิม | ตอนนี้ |
| --- | --- |
| ตั้ง Wi-Fi กลับเป็น DHCP แล้ว gateway เก่ายังค้างใน registry ทำให้มี default route สองเส้น ต้องเสียบสาย LAN เพื่อ reset | ลบ default route ทั้งใน PersistentStore และ ActiveStore ก่อนเปลี่ยนทุกครั้ง แล้วอ่านค่ากลับมาตรวจ |
| V3 สั่ง disable Wi-Fi ก่อนตั้ง DHCP แต่ netsh ตั้งค่าการ์ดที่ถูก disable ไม่ได้ และ error ถูกซ่อนด้วย `>nul` จึงไม่ได้ล้างจริง | ไม่ disable การ์ด ตั้งค่าตรงๆ ผ่าน NetTCPIP และแสดง error จริง |
| ชื่อการ์ดฝังในไฟล์ (`WI-FI 2`, `Ethernet 2`, `Wi-Fi`, `Ethernet`) ใช้กับเครื่องอื่นไม่ได้ | หาการ์ดเองจากชนิด (802.3 / 802.11) หรือเลือกในหน้าตั้งค่า |
| ต้องแก้ IP ในไฟล์ .bat เอง และไม่มีการตรวจ | ใส่ในหน้าตั้งค่า ตรวจ IP, mask, gateway อยู่วงเดียวกัน, DNS ก่อนบันทึก |
| `netsh ... add dns ... DHCP` เป็นคำสั่งที่ผิด | ใช้ `Set-DnsClientServerAddress -ResetServerAddresses` |
| ไม่ตรวจว่ารันแบบ admin หรือไม่ ขึ้น "completed successfully" เสมอ | ขอสิทธิ์ admin เอง และรายงานผลจริงของแต่ละการ์ด พร้อม ping gateway |
| IP เดียวกันอาจค้างอยู่บนการ์ดอื่น ทำให้ตั้งไม่ได้ | ลบ IP ซ้ำจากการ์ดอื่นก่อน และตั้ง DHCP ให้การ์ดเดิมก่อนใส่ static ให้การ์ดใหม่ |
| กดซ้ำก็ reset การ์ดที่ใช้อยู่ ทำให้หลุดชั่วครู่ | การ์ดที่ค่าถูกอยู่แล้วจะไม่ถูกแตะ |

ไอคอน `ip-switch.ico` สร้างด้วย `make-icon.ps1` (คัดลอกไปที่ `..\.icons\ip-switch.ico` ให้การ์ดใน OffLab ด้วย)

ข้อควรรู้: Static IP ที่ตั้งบน Wi-Fi ใช้กับทุกเครือข่าย Wi-Fi ไม่ใช่เฉพาะ Wi-Fi ของ รพ. ออกนอก รพ. ให้กด **อัตโนมัติ**
